## Overview

This repository contains the practical report for **Practical 1** of the Recombinant DNA Technologies course.

The practical involved retrieving, annotating, and analysing the complete coding sequence (CDS) of the **phytoene synthase 2a (PSY2a)** gene from *Musa troglodytarum* using the NCBI nucleotide database.

### Key Activities Performed:
- Retrieval of the gene sequence from NCBI
- Examination of sequence features (start codon, stop codon, CDS)
- Calculation of gene length and coding region length
- Basic annotation and biological interpretation of the gene
